## What it is
A college project that brings mechanical keyboards and accessories to an online shop, inspired by stackskb.com. It includes an admin area.

The screen layouts are documented in a separate PDF, linked above as screen layouts.

## The problem
Buying a keyboard means comparing layouts, switches and accessories. A shop has to make that comparison easy, and the owner needs a simple way to keep the catalogue up to date.

## What I built
A storefront with product pages and a cart, plus an admin area for adding products and managing what is on sale.

## What was hard
Product data that varies a lot between items, and keeping the admin forms simple enough to use quickly.

## Result
A complete browse-to-cart flow with a working admin area. It was built as a college project and is not a live shop.
