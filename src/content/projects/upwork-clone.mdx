## What it is
A working prototype that replicates core Upwork features. Clients post projects, review bids and hire freelancers. Freelancers build profiles, submit proposals and manage a dashboard. An admin dashboard shows signups, jobs and revenue, and manages proposals and categories.

The screen layouts are documented in a separate PDF, linked above as screen layouts.

## The problem
Freelancing marketplaces look simple from the outside, but three kinds of user need three different views of the same data. The goal was to see how much of that flow I could build end to end.

## What I built
Separate dashboards for clients, freelancers and admins, with job posting, proposals, hiring and a basic admin overview. The screens were designed first, then built one flow at a time.

## What was hard
Keeping permissions clear. Each action (posting, bidding, hiring, approving) has to be allowed for exactly the right user and nobody else.

## Result
A prototype where the main flows work from start to finish. Payments and messaging are left out on purpose.
