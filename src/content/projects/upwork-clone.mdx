## What it is
A working prototype that replicates core Upwork features. Clients post projects, review bids and hire freelancers. Freelancers build profiles, submit proposals and manage a dashboard. An admin dashboard shows signups, jobs and revenue, and manages proposals and categories.

The screen layouts are documented in a separate PDF, linked above as docs.
